# GTA VI Rich Presence

Unofficial GTA VI Discord Rich Presence.

The program automatically changes your Discord Rich Presence using randomized activities.

## Requirements

* Windows
* Python 3
* Discord
* Git

## Quick Start — Command Prompt

### 1. Install Git

Download and install Git from:

https://git-scm.com/

Make sure Python 3 is also installed.

### 2. Open Command Prompt

Press:

```text
Win + R
```

Type:

```text
cmd
```

and press **Enter**.

### 3. Go to your Desktop

```cmd
cd %USERPROFILE%\Desktop
```

### 4. Clone the repository

Replace `YOUR_USERNAME` with the GitHub username that owns the repository:

```cmd
git clone https://github.com/Dantezz025/GTA6-Rich-Presence.git
```

### 5. Enter the project folder

```cmd
cd GTA6-Rich-Presence
```

### 6. Start the program

```cmd
start.bat
```

The launcher will automatically:

1. Create a Python virtual environment.
2. Install the required libraries.
3. Start the Rich Presence.

You do **not** need to manually install `pypresence`.

### Copy-Paste Version

Once Git and Python are installed, you can copy and paste these commands:

```cmd
cd %USERPROFILE%\Desktop
git clone https://github.com/Dantezz025/GTA6-Rich-Presence.git
cd GTA6-Rich-Presence
start.bat
```

## Updating the Program

If you already have the repository and want to download the latest version:

```cmd
cd %USERPROFILE%\Desktop\GTA6-Rich-Presence
git pull
start.bat
```

## Installation — Alternative

You can also download the repository as a ZIP file from GitHub.

After downloading:

1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click `start.bat`.

The launcher will automatically install the required Python libraries.

## Discord

Make sure Discord is running before starting the program.

## Stopping

Press `Ctrl+C` in the Command Prompt window to stop the Rich Presence.
